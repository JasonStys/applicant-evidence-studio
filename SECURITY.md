# Security and privacy — private accounts (0.2)

Created by Jason Stys. Never expose the old plaintext `serve` loopback developer
mode publicly. Use the `accounts` service or explicit HTTPS deployment factory.
Never commit real applicant records, credentials, backups or exports.

Private mode processes resumes only in the browser and persists versioned
ciphertext. It has no administrator document-view API. Host account metadata,
malicious future code, weak phrases and compromised devices are outside that
passive-storage privacy guarantee. No absolute safety, anonymity or production
certification is claimed. Read [the threat model](docs/private-accounts.md) and
[hosting gates](docs/hosting.md) before real organizational use. Native builds are
unsigned; verify official checksums and publisher provenance. Report security
issues privately to Jason through the contact path in the UI; do not attach
resumes, credentials, encryption/recovery secrets or exploit data in public issues.
