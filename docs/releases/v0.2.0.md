# Applicant Evidence Studio 0.2 — created by Jason Stys

Real account registration/login, opaque expiring cookies, random login recovery
codes, and independent browser-encrypted workspaces. Local evidence scoring,
coaching and PDF/DOCX/TXT parsing; no private resume processing by the host.
Encrypted backup/restore, conflict protection, explicit live-account deletion,
help, contact links and installed-web-app metadata.

Download your matching OS/architecture archive and its `.sha256`. Verify the full
hash, extract, and launch ApplicantEvidenceStudio. Python and Node are bundled;
no command setup is needed. It runs a loopback-only service and opens your default
browser. Local accounts are separate from hosted accounts. See INSTALL.md inside
the archive and [install instructions](https://github.com/JasonStys/applicant-evidence-studio/blob/main/docs/install.md).

These are **unsigned portable executables**, not Windows Store/MSI packages or
notarized macOS apps. OS and antivirus warnings can occur. Checksums do not replace
code signing or publisher verification. Linux targets glibc 2.35+ (Ubuntu 22.04+);
builds do not claim support for every distribution, CPU or older OS. Mobile uses
the hosted website/installable web app, not these desktop binaries.

Save both your unique vault phrase and encrypted backups. Login recovery CANNOT
recover your vault phrase. No administrator backdoor or document sharing exists.
The host can see minimal account metadata; a malicious host or infected browser
can still compromise unlocked data. Plaintext exports are your responsibility.

Advisory review only: not a hiring decision, legal-compliance certification or
validated predictor of job success. Always read original evidence yourself.
The public account service needs an approved HTTPS host and retention/security
operations; GitHub itself does not host the Python account service.
