# Applicant Evidence Studio 0.3.1

By Jason Stys. The native owner window provides Open workspace, readable Help,
bundled Runtime notices and graceful Quit. The private-account browser application
retains evidence comparison, coaching, encrypted saves and factual exports.
CPython 3.14.10, PyInstaller 6.22.3 and actual Tcl/Tk patch levels are recorded in
the bundled source manifest. Startup verifies source/runtime/resource coherence
before account initialization.

The existing per-user account directory and encrypted-workspace format remain
unchanged. Exclusive profile ownership and ordinary single-link database/recovery
file checks prevent overlapping native owners and accidental linked-file writes.
Normal Quit drains active work before releasing the account-store lock. Back up
encrypted exports and the stopped account directory before upgrading.

Downloads are unsigned portable applications: Windows AMD64, Ubuntu24.04-compatible
Linux x86-64 and macOS ARM64. No Python/Node installation is needed for normal use.
Mobile uses a compatible browser or installed web app. These packages do not
provision a public account server, add telemetry or make external AI/source calls
from private mode. See INSTALL.md and the included runtime notices.

The six assets consist of one archive and SHA-256 sidecar per desktop platform.
Each new archive includes the executable, LICENSE, INSTALL.md, NATIVE_SOURCE.json
and NATIVE_NOTICES.txt. Published 0.3.0 assets are preserved. New releases remain
drafts until exact-source CI, processed CodeQL, real extracted-app acceptance and
independent download/install checks complete. Checksums identify bytes; these
packages are not signed installers or notarized macOS app bundles.
