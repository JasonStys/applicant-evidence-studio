# Applicant Evidence Studio0.3 — source-linked evidence comparison

Created by Jason Stys. This release adds a read-only, user-selected two-record comparison for authorized applicant evidence. It does not select a winner or make hiring decisions.

- Capture the same rubric and exact record revisions; compare reviewed criterion attainment, strongest source/locator references, source warnings, alternative reviewed claims and excluded unreviewed claims.
- Clarification prompts preserve unknown evidence and explicit unclear/transfer chronology without guessing degrees, failures or paid experience.
- Optional human observations and exact captured JSON export stay local. Private accounts perform comparison entirely in the unlocked browser, with no plaintext endpoint, AI call or workspace write. Developer mode reads one authenticated SQL snapshot.
- Selection/rubric changes, mutations, locks and stale asynchronous responses invalidate the view. Names, raw sources, private notes and employment-month totals are omitted from the comparison export; evidence summaries and human observations may still contain personal information. Exports are unencrypted private files, not anonymized/signed evidence.
- Updated PDF-parser, URI-validation and build-tool security patches; exact runtime/development version snapshot and expanded independent/real-browser regression gates.

## Installation and upgrade

Download the archive matching your operating system/architecture and its SHA-256 manifest from the official release. Verify the entire hash before extracting/launching. Python, built UI and loopback account service are bundled; ordinary users need no Python/Node commands. Builds remain unsigned portable executables, not signed MSI/notarized native apps. Linux compatibility follows the existing Ubuntu22.04/glibc2.35 build target. Mobile uses the website/installable web app, not a desktop executable. See [installation](https://github.com/JasonStys/applicant-evidence-studio/blob/main/docs/install.md).

Account storage paths, login/vault derivation, ciphertext-envelope version and workspace schema remain unchanged. No account or vault migration is introduced. Keep independent encrypted backups and your vault phrase; software upgrades cannot recover a lost phrase. Existing0.2 releases/assets are preserved. This new tag may be published only after validation succeeds for the exact source commit and all three native builds pass their packaged smoke tests, including0.3 health and comparison UI assets.

Advisory prototype only: not a validated predictor, bias-free/legally compliant hiring system or production release authority. Read original applications and cited work yourself. Public hosting still requires an independently approved HTTPS service and operational controls; this source/release does not provision one.
